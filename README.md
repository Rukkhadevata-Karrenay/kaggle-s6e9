## 数据与任务

- 训练数据668,665行，测试数据286,571行，原始13个预测特征。
- 目标为购买意向：Yes=1，No=0；ID不进入预测特征。
- 比较人口属性、收入、通勤、充电条件和相关特征表示下的分类模型。

## 方法

**特征工程：**数值取值视作类别的目标编码、频率编码、有限类别交互、收入数位和通勤小数位、合成数据生成机制相关特征，以及官方关联原始公开数据的按值均值与计数映射。

**验证：**采用分层交叉验证并保存完整折外预测（OOF）。目标编码仅在外层训练折拟合，训练折内部再交叉拟合，之后变换外层验证折和测试集。部分无标签频率信息使用train+test特征列，属于转导式特征处理；另有折内频率消融检查。

**最终融合：**三个划分种子 × LightGBM、XGBoost、CatBoost，每组10折；九组成员的OOF与测试预测等权平均，不搜索最终融合权重。正式成员使用固定训练轮数。

## 实验演进

| 模型/阶段 | OOF AUC | Public | Private |
|---|---:|---:|---:|
| 逻辑回归基线 | 0.9380912 | 0.93738 | 0.93690 |
| HistGradientBoosting | 0.9413926 | 0.94126 | 0.94065 |
| 原始特征CatBoost深度实验最佳 | 0.9418591 | 未提交 | 未提交 |
| 特征工程 + LightGBM（A） | 0.9460181 | 0.94632 | 0.94533 |
| 三模型10折融合（B） | 0.9462079 | 未提交 | 未提交 |
| 三划分 × 三模型10折融合（C） | 0.9463020 | 0.94630 | 0.94536 |

主要改善来自特征表示。候选A去掉目标编码后OOF为0.9440118，支持目标编码的重要性。早期未满足预设门槛的小幅改进没有直接提交。多轮复用同一训练集存在选模偏差，不把OOF称为独立测试集。
